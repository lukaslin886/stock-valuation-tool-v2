# 持股分析工具 (Portfolio Analyzer)

自動分析持股並生成賣出/持有建議報告

## 📋 功能特色

- ✅ **自動 CSV 偵測** - 自動找到最新的持股明細檔案
- ✅ **純中文名稱支援** - 支援「台積電」等純中文名稱自動對應股票代碼
- ✅ **智能分類** - ETF 排除、金融股保護、核心龍頭保護
- ✅ **DCF 估值整合** - 完整的現金流折現法估值分析
- ✅ **Excel 報告** - 5 個工作表的詳細分析報告
- ✅ **一鍵執行** - 透過 .bat 批次檔快速執行

## 🚀 快速開始

### 1. 準備持股 CSV 檔案

將您的持股明細 CSV 檔案放入 `MY_STOCK/` 資料夾。

**必要欄位**：
- 股票名稱
- 股數
- 成交均價
- 市價
- 報酬率

### 2. 執行分析

**方法 A：雙擊執行（推薦）**
```
直接雙擊 run_analysis.bat
```

**方法 B：命令列執行**
```bash
cd stock-valuation-tool
python -m portfolio_analyzer.run_analysis
```

### 3. 查看報告

報告會儲存在 `reports/` 資料夾中，檔名格式：
```
portfolio_analysis_YYYYMMDD_HHMMSS.xlsx
```

## 📊 報告內容

Excel 報告包含 5 個工作表：

1. **賣出建議** - 按優先級排序的賣出清單
   - 🔴 優先級 A：強烈建議賣出
   - 🟡 優先級 B：考慮賣出

2. **續抱建議** - 建議持有的股票清單

3. **保護名單** - 金融股與核心龍頭（長期持有）
   - 核心龍頭：2330 台積電、2317 鴻海
   - 金融股：14 支（彰銀、國泰金等）

4. **分析明細** - 完整的分析數據

5. **未分析清單** - 跳過的股票與原因

## 🎯 分析邏輯

### 階段 1：快速篩選
符合以下任一條件的股票進入 DCF 分析：
- 獲利 > 30%
- 虧損 < -20%
- 部位價值 > $50,000

### 階段 2：DCF 估值分析
- 獲取最新 EPS
- 計算歷史成長率
- 執行 DCF 內在價值計算
- 比較市價與內在價值

### 賣出建議邏輯

**優先級 A（強烈建議）**：
- 高估 ≥ 30% + 獲利 ≥ 50% + DCF 不建議

**優先級 B（考慮賣出）**：
- 高估 ≥ 15%
- 獲利 30%-50% + DCF 可考慮
- 虧損 < -30% + DCF 不建議（停損考慮）

**保護名單特殊處理**：
- 僅在高估 ≥ 50% 時才建議賣出
- 其他情況一律建議長期持有
