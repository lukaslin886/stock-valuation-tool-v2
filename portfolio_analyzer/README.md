# 持股分析工具 (Portfolio Analyzer)

自動分析持股並生成賣出/持有建議報告

## 📋 功能特色

- ✅ **自動 CSV 偵測** - 自動找到最新的持股明細檔案
- ✅ **純中文名稱支援** - 支援「台積電」等純中文名稱自動對應股票代碼
- ✅ **智能分類** - ETF 排除、金融股保護、核心龍頭保護
- ✅ **DCF 估值整合** - 完整的現金流折現法估值分析
- ✅ **加碼機會分析** - 自動偵測低估且適合加碼的持股（v1.1 新增）
- ✅ **Excel 報告** - 6 個工作表的詳細分析報告
- ✅ **一鍵執行** - 透過 .bat 批次檔快速執行

## 🚀 快速開始

### 1. 準備持股 CSV 檔案

將您的持股明細 CSV 檔案放入 `MY_STOCK/` 資料夾。

**必要欄位**：
- 股票名稱
- 股數
- 成交均價
- 市價
- 報酬率

### 2. 執行分析

**方法 A：雙擊執行（推薦）**
```
直接雙擊 run_analysis.bat
```

**方法 B：命令列執行**
```bash
cd stock-valuation-tool
python -m portfolio_analyzer.run_analysis
```

### 3. 查看報告

報告會儲存在 `reports/` 資料夾中，檔名格式：
```
portfolio_analysis_YYYYMMDD_HHMMSS.xlsx
```

## 📊 報告內容

Excel 報告包含 6 個工作表：

1. **賣出建議** - 按優先級排序的賣出清單
   - 🔴 優先級 A：強烈建議賣出
   - 🟡 優先級 B：考慮賣出

2. **續抱建議** - 建議持有的股票清單

3. **保護名單** - 金融股與核心龍頭（長期持有）
   - 核心龍頭：2330 台積電、2317 鴻海
   - 金融股：14 支（彰銀、國泰金等）

4. **分析明細** - 完整的分析數據

5. **加碼機會** - 持股中適合加碼的標的（v1.1 新增）
   - 🟢 優先級 A：強烈推薦加碼
   - 🔵 優先級 B：建議加碼
   - ⚪ 優先級 C：可考慮加碼

6. **未分析清單** - 跳過的股票與原因

## 🎯 分析邏輯

**📖 詳細策略說明請參閱：[STRATEGY.md](./STRATEGY.md)**

### 階段 1：快速篩選
符合以下任一條件的股票進入 DCF 分析：
- 獲利 > 30%（可在 `config.py` 調整）
- 虧損 < -20%（可在 `config.py` 調整）
- 部位價值 > NT$500（可在 `config.py` 調整）

### 階段 2：DCF 估值分析
- 獲取最新 EPS
- 計算歷史成長率
- 執行 DCF 內在價值計算
- 比較市價與內在價值

### 賣出建議邏輯

**優先級 A（強烈建議）**：
- 高估 ≥ 30% + 獲利 ≥ 50% + DCF 不建議

**優先級 B（考慮賣出）**：
- 高估 ≥ 15%
- 獲利 30%-50% + DCF 可考慮
- 虧損 < -30% + DCF 不建議（停損考慮）

**保護名單特殊處理**：
- 僅在高估 ≥ 50% 時才建議賣出
- 其他情況一律建議長期持有

### 加碼建議邏輯（v1.1 新增）

**加碼條件（須同時滿足）**：
- DCF 低估 > 15%
- DCF 建議：推薦或強烈推薦買入
- 潛在報酬率 > 20%
- 部位未達上限（一般股票 < 15%，保護名單 < 20%）
- 目前報酬率 > -30%（避免攤平風險）

**優先級分類**：
- **優先級 A**：低估 > 30% + DCF 強烈推薦 + 部位 < 10%
- **優先級 B**：低估 15%-30% + DCF 推薦 + 部位 < 15%
- **優先級 C**：符合基本條件但接近部位上限

**建議加碼價位**：內在價值的 85%（保守估計）

**注意事項**：
- ⚠️ 負債比限制功能（預留，待未來實作）
- ⚠️ 加碼建議僅供參考，投資決策請自行判斷

## ⚙️ 策略配置

### 配置檔
所有策略參數集中在 [`config.py`](./config.py)，修改後立即生效：
- 篩選條件（獲利/虧損/部位門檻）
- 賣出策略（高估門檻、停損門檻）

- 保護名單（金融股、核心龍頭）
