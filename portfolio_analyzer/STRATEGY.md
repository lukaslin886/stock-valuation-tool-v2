## 策略總覽

持股分析工具採用**兩階段篩選 + DCF 估值**的分析流程：

```
持股清單
    ↓
階段 1：快速篩選（篩選重點持股）
    ↓
階段 2：DCF 估值分析（計算內在價值）
    ↓
產生三類建議：
1. 賣出建議（優先級 A/B）
2. 續抱建議
3. 加碼建議（優先級 A/B/C）
```

### 核心策略理念

1. **聚焦重點**：優先分析高獲利、高虧損或大部位的持股
2. **價值投資**：基於 DCF 內在價值判斷買賣時機
3. **風險控管**：設定部位上限、虧損停損門檻
4. **長期持有**：保護名單（金融股、核心龍頭）給予更大容忍度

## 篩選策略參數

所有參數定義在 [`config.py`](./config.py) 檔案中，修改後立即生效。

### 2.1 階段 1：快速篩選

**目的**：從持股清單中篩選出需要深入分析的股票

**符合以下任一條件進入 DCF 分析**：

| 參數名稱 | 當前值 | 說明 | 建議範圍 | 調整效果 |
|---------|--------|------|---------|---------|
| `PROFIT_THRESHOLD` | 30% | 獲利門檻 | 20-40% | 降低→分析更多獲利股<br>提高→只分析大獲利股 |
| `LOSS_THRESHOLD` | -20% | 虧損門檻 | -10% ~ -30% | 提高（-10%）→更敏感<br>降低（-30%）→更寬容 |
| `POSITION_THRESHOLD` | NT$500 | 部位門檻 | 500-100,000 | 降低→分析更多小部位<br>提高→只關注大部位 |

**範例說明**：

```python
# 目前設定：NT$500 門檻
部位 NT$12,000 的聯電 → ✅ 會分析（超過 NT$500）
部位 NT$350 的長榮 → ❌ 不分析（低於 NT$500 且報酬率正常）

# 如果改為 NT$50,000
部位 NT$12,000 的聯電 → ❌ 不分析（低於 NT$50,000 且報酬率正常）
部位 NT$80,000 的台積電 → ✅ 會分析（超過 NT$50,000）
```

### 2.2 賣出建議策略

**優先級 A：強烈建議賣出**

| 參數名稱 | 當前值 | 觸發條件 |
|---------|--------|---------|
| `SELL_A_OVERVALUE` | 30% | 高估程度 ≥ 30% |
| `SELL_A_PROFIT` | 50% | 且獲利 ≥ 50% |
| - | - | 且 DCF 建議「不建議」 |

**範例**：
- 台積電：高估 35%、獲利 55%、DCF「不建議」→ 🔴 優先級 A（強烈建議賣出）

---

**優先級 B：考慮賣出**

符合以下任一條件：

| 條件 | 參數名稱 | 當前值 | 說明 |
|-----|---------|--------|------|
| 條件 1 | `SELL_B_OVERVALUE` | 15% | 高估 ≥ 15% |
| 條件 2 | `SELL_B_PROFIT_MIN`<br>`SELL_B_PROFIT_MAX` | 30%<br>50% | 獲利 30-50% + DCF「可考慮」 |
| 條件 3 | `SELL_B_LOSS` | -30% | 虧損 < -30% + DCF「不建議」（停損） |

**範例**：
- 鴻海：高估 18% → 🟡 優先級 B（考慮賣出）
- 聯電：獲利 35%、DCF「可考慮」→ 🟡 優先級 B
- 長榮：虧損 -35%、DCF「不建議」→ 🟡 優先級 B（停損考慮）

---

**保護名單特殊規則**

| 參數名稱 | 當前值 | 說明 |
|---------|--------|------|
| `PROTECTED_OVERVALUE` | 50% | 保護名單僅在高估 ≥ 50% 時才建議賣出 |

**範例**：
- 國泰金（保護名單）：高估 35% → ⚪ 續抱（未達 50% 門檻）
- 國泰金（保護名單）：高估 55% → 🟡 優先級 B（嚴重高估才賣）

### 2.3 加碼建議策略

**篩選邏輯（v1.3.0 更新：靈活篩選）**

系統採用**兩階段靈活篩選**機制：

**階段 1：強條件檢查（符合任一即通過）**

| 參數名稱 | 當前值 | 說明 |
|---------|--------|------|
| `BUY_STRONG_UNDERVALUED` | -20% | 嚴重低估門檻 |
| `BUY_STRONG_UPSIDE` | 30% | 高潛在報酬門檻 |

只要符合以下**任一強條件**，即使另一條件不足也會進入加碼候選：
- 低估程度 < -20%（嚴重低估）
- 潛在報酬率 > 30%（高報酬機會）

**階段 2：基本門檻檢查（須同時滿足）**

如果不符合強條件，才檢查基本門檻（須**同時**滿足）：

| 參數名稱 | 當前值 | 說明 |
|---------|--------|------|
| `BUY_MIN_UNDERVALUED` | -15% | 基本低估門檻 |
| `BUY_MIN_UPSIDE` | 20% | 基本潛在報酬門檻 |

**其他必要條件**

| 參數名稱 | 當前值 | 說明 |
|---------|--------|------|
| `BUY_MAX_POSITION_NORMAL` | 15% | 一般股票部位上限 < 15% |
| `BUY_MAX_POSITION_PROTECTED` | 20% | 保護名單部位上限 < 20% |
| `BUY_MAX_LOSS` | -30% | 目前報酬率 > -30% |
| - | - | DCF 建議「推薦」或「強烈推薦」 |

---

**範例說明**：

```
情境 1：符合強條件（嚴重低估）
台積電：低估 -25%、潛在報酬 18%、部位 8%、DCF「強烈推薦」
✅ 通過！雖然潛在報酬未達 20%，但低估超過 20% 強條件

情境 2：符合強條件（高潛在報酬）
鴻海：低估 -12%、潛在報酬 35%、部位 10%、DCF「推薦」
✅ 通過！雖然低估未達 15%，但潛在報酬超過 30% 強條件

情境 3：不符合強條件，檢查基本門檻
聯電：低估 -18%、潛在報酬 25%、部位 12%、DCF「推薦」
✅ 通過！低估 18% > 15%，潛在報酬 25% > 20%，同時滿足基本門檻

情境 4：不符合任何條件
長榮：低估 -10%、潛在報酬 15%、部位 8%、DCF「推薦」
❌ 不通過！不符合強條件，且基本門檻也未同時滿足

情境 5：部位已達上限
台積電：低估 -25%、潛在報酬 35%、部位 16%、DCF「強烈推薦」
❌ 不通過！雖然估值條件優秀，但部位 16% 已超過上限 15%
```

**優先級分類**

| 優先級 | 低估門檻 | DCF 建議 | 部位限制 | 說明 |

- 台積電：低估 35%、DCF「強烈推薦」、部位 8% → 🟢 優先級 A
- 鴻海：低估 22%、DCF「推薦」、部位 12% → 🔵 優先級 B

## 滑動風險模型策略

### 7.1 什麼是滑動風險（Slippage）？

**定義**：
滑動風險（Slippage）是指**實際成交價格**與**預期價格**之間的差異。

**範例**：
```
預期買入價：NT$100
實際成交價：NT$101.5
滑動成本：NT$1.5（1.5%）
```

**影響因素**：
1. **價格波動**：股價波動越大，滑價風險越高
2. **流動性**：成交量越低，滑價越嚴重
3. **訂單大小**：訂單越大，對市場衝擊越大

---

### 7.2 為什麼需要滑動風險模型？

**問題場景**：

```
DCF 計算：台積電內在價值 NT$650
建議買入價：NT$552.5（85% 安全邊際）

❌ 理想情況（忽略滑價）：
下單買入 → 成交價 NT$552.5 → 實際買入

✅ 現實情況（考慮滑價）：
下單買入 → 股價波動上漲 → 成交價 NT$558.3
實際滑價成本：NT$5.8（1.05%）
```

**不考慮滑價的風險**：
- ❌ 實際買入價格可能高於預期
- ❌ 獲利空間被壓縮
- ❌ 風險報酬比失真

**考慮滑價的優勢**：
- ✅ 更真實的成本估算
- ✅ 更準確的報酬預測
- ✅ 更合理的投資決策

---

### 7.3 滑動風險模型架構

我們的模型採用**混合計算方式**，綜合考量三大因素：

```
總滑價 = 波動性滑價 × 40% + 流動性滑價 × 30% + 市場衝擊滑價 × 30%
```

#### 7.3.1 波動性滑價（40% 權重）

**計算基礎**：最近 2 根 K-bars 的價格波動

**判斷邏輯**：
- **買入**：股價可能向上波動 → 買貴風險
- **賣出**：股價可能向下波動 → 賣便宜風險

**範例**：
```
K1（參考日）：開 100、高 105、低 98、收 103
K2（交易日）：開 103、高 108、低 101、收 106

波動幅度 = (高點 - 低點) / 基準價
買入風險 = 可能買在接近高點（108）
賣出風險 = 可能賣在接近低點（101）
```

---

#### 7.3.2 流動性滑價（30% 權重）

**分級標準**：根據日平均成交量

| 流動性等級 | 成交量範圍 | 滑價率範圍 | 代表股票 |
|-----------|-----------|-----------|---------|
| 🟢 高流動性 | ≥ 10萬股/日 | 0.1-0.3% | 台積電、鴻海 |
| 🟡 中流動性 | ≥ 1萬股/日 | 0.3-0.7% | 一般上市股 |
| 🟠 低流動性 | ≥ 1千股/日 | 0.7-1.5% | 冷門股 |
| 🔴 極低流動性 | < 1千股/日 | 1.5-3.0% | 超冷門股 |

**流動性閾值配置**：
```python
# config.py
LIQUIDITY_HIGH_THRESHOLD = 100000      # 高流動性 ≥ 10萬股
LIQUIDITY_MEDIUM_THRESHOLD = 10000     # 中流動性 ≥ 1萬股  
LIQUIDITY_LOW_THRESHOLD = 1000         # 低流動性 ≥ 1千股
```

---

#### 7.3.3 市場衝擊滑價（30% 權重）

**分級標準**：訂單大小佔日均量的比例

| 市場衝擊等級 | 訂單大小 | 滑價率範圍 | 說明 |
|------------|---------|-----------|------|
| 🟢 小單 | < 1% 日均量 | 0.05-0.2% | 對市場幾乎無影響 |
| 🟡 中單 | 1-5% 日均量 | 0.2-0.8% | 可能造成短期波動 |
| 🔴 大單 | > 5% 日均量 | 0.8-2.0% | 顯著影響市場價格 |

**市場衝擊閾值配置**：
```python
# config.py
MARKET_IMPACT_SMALL_THRESHOLD = 0.01   # 小單 < 1%
MARKET_IMPACT_MEDIUM_THRESHOLD = 0.05  # 中單 < 5%
# > 5% = 大單
```

**範例**：
```
台積電日均量：50,000 股
我的訂單：300 股

訂單佔比 = 300 / 50,000 = 0.6% < 1%
市場衝擊等級：小單 → 滑價率約 0.1%
```

---

### 7.4 配置參數說明

所有滑動風險參數定義在 `config.py` 的「滑動風險模型配置」區塊。

#### 7.4.1 總開關

```python
ENABLE_SLIPPAGE = True  # 啟用滑動風險模型
```

**設為 `False`**：
- 所有計算使用理論價格
- 不考慮滑價成本
- 適合純理論分析

**設為 `True`**：
- 買入價格向上調整（加滑價）
- 賣出價格向下調整（減滑價）
- 更貼近實際交易

---

#### 7.4.2 權重配置

```python
SLIPPAGE_WEIGHT_VOLATILITY = 0.4    # 波動性權重 40%
SLIPPAGE_WEIGHT_LIQUIDITY = 0.3     # 流動性權重 30%
SLIPPAGE_WEIGHT_MARKET_IMPACT = 0.3 # 市場衝擊權重 30%
```

**重要**：三個權重總和必須為 1.0

**調整建議**：
- **注重價格波動** → 提高 `VOLATILITY` 權重（例如 0.5）
- **注重成交量** → 提高 `LIQUIDITY` 權重（例如 0.4）
- **注重大單影響** → 提高 `MARKET_IMPACT` 權重（例如 0.4）

---

#### 7.4.3 流動性閾值

## 策略設計原則

1. **長期持有**
   - 短期價格波動不應影響決策
   - 基於內在價值而非市場情緒

2. **安全邊際**
   - 買入時留有 15% 安全邊際（85% 價位）
   - 賣出時給予適當容忍範圍

3. **分散風險**
   - 單一股票部位上限 15-20%
   - 避免過度集中

---

### 5.2 風險管理原則

1. **停損機制**
   - 虧損超過 -30% 且 DCF 不建議 → 考慮停損
   - 避免攤平虧損過大的持股

2. **部位控管**
   - 一般股票 ≤ 15%
   - 保護名單 ≤ 20%
   - 總持股建議 8-12 檔

3. **分批進出**
   - 建議分批加碼（不一次全買）
   - 建議分批賣出（不一次全賣）

---

### 5.3 保護名單設計

**為什麼需要保護名單？**

1. **金融股特性**
   - 景氣循環股，短期波動大
   - 長期穩定配息
   - 不適合短線進出

2. **核心龍頭**
   - 台股權值核心
   - 長期競爭力強
   - 適合長期持有

3. **更高容忍度**
   - 高估 50% 才建議賣出（一般股票 15%）
   - 部位上限 20%（一般股票 15%）

### Q1：部位門檻設定 NT$500 太低了嗎？

**A**：取決於您的投資組合規模

**建議**：
- 總資產 < NT$100 萬 → NT$500-5,000 合理
- 總資產 NT$100-500 萬 → NT$10,000-30,000
- 總資產 > NT$500 萬 → NT$50,000-100,000

**調整方法**：

```python
# config.py
POSITION_THRESHOLD = 10000  # 改為 NT$10,000
```

### Q2：為什麼有些股票沒被分析？

**A**：可能原因：

1. **報酬率在正常範圍內**（-20% 到 30%）
2. **部位太小**（低於門檻）
3. **是 ETF**（自動排除）

**解決方案**：
- 降低 `PROFIT_THRESHOLD`（例如改為 20%）
- 提高 `LOSS_THRESHOLD`（例如改為 -15%）
- 降低 `POSITION_THRESHOLD`（例如改為 500）
